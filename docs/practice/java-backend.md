# ⚙️ Java 后端模拟面试

本路线按学习收益排序，不声称代表某家公司题目频率。先修 Java 基础、SQL 和本地事务。每轮选择一个主线项目，避免把所有术语堆进同一次回答。

## 三层准备目标

| 层次 | 内容 | 达标表现 |
| --- | --- | --- |
| 先完成 | Java 对象契约、集合、事务、索引、线程池 | 不看答案解释机制和边界 |
| 再深入 | MVCC、锁实验、传播行为、缓存竞态 | 写出执行顺序并推导结果 |
| 最后连接项目 | 库存预占、审批补偿、RPC 重试 | 解释正常与失败路径并给测试 |

## 一轮 60 分钟训练示例

| 环节 | 问题与追问 | 验收 |
| --- | --- | --- |
| 5 分钟：项目开场 | 用一句话说明需求、约束和自己负责的部分 | 不虚构上线或性能数字 |
| 10 分钟：并发 | [Q-JAVA-02：最大线程数大为何仍堆积？](../backend/jmm-threadpool.md#q-java-02) → 下游连接耗尽怎么办？ | 画出核心→队列→扩容→拒绝 |
| 10 分钟：数据库 | [Q-DB-01：RR 旧版本](../backend/mysql-mvcc.md#q-db-01) → 当前读如何不同？ | 按双事务顺序推导 |
| 10 分钟：一致性 | [Q-CACHE-02：Outbox](../backend/cache-outbox.md#q-cache-02) → 旧读晚回填怎么办？ | 区分传播可靠性和缓存竞态 |
| 15 分钟：算法 | [前缀和与单调栈](../algorithms/prefix-stack.md) 中任选一题 | 独立写代码、复杂度、反例 |
| 10 分钟：项目深挖 | [库存释放与扣减竞争](../projects/inventory-reservation.md#q-project-02) | 写条件更新并解释事务边界 |

时间是练习安排，不是任务执行预计耗时。可以拆成几次练习，但保留闭卷口述和独立编码。

## 评分关注点

能背出“加分布式锁”只到定义层；能解释锁过期后为什么仍需状态与幂等，才进入机制层。能写出 RESERVED 到两个互斥终态的条件更新、并构造冲突测试，才达到实现和验证层。

## 复盘方向

线程池错题回到 [JMM/线程池](../backend/jmm-threadpool.md)；事务边界回到 [Spring/MyBatis](../backend/spring-mybatis.md)；死锁与锁范围回到 [InnoDB 实验](../backend/mysql-locking.md)。将不会的题标为 0–2 分，再通过 [自测题库](./README.md) 的未掌握筛选复访。
