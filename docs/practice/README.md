## 评分的含义

0：不会；1：能背定义；2：能解释机制和前提；3：能写实现或推导并应对反例；4：有可复现测试、数据或实验支撑。评分是自评，不是自动能力测评，也不是面试通过预测。

评分只保存在当前浏览器的 localStorage，不上传、不自动跨设备同步。清理网站数据会删除评分；可以导出 JSON 备份，在另一个浏览器导入。导入仅接受已知题目 ID 与 0–4 整数评分，其他项目不会变成新题目。

浏览器存储被禁用时仍可阅读与筛选，保存失败会显示提示。无法使用交互组件时，可通过 [专题索引](../guide/question-bank.md) 和上述岗位路线阅读内容。

## 一次练习怎样结束？

不要以“看完答案”结束。写下原回答遗漏的前提，补一个最小反例，再用自己的语言重答一次；在 [复盘模板](./review-template.md) 中留下证据和下次要验证的问题。
