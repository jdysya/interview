# 📝 面试与错题复盘模板

复制到自己的笔记后填写。不要在公共仓库写真实公司内部信息、个人联系方式、未公开代码或敏感数据。模板不自动上传你的面试记录。

```markdown
# 一次练习复盘
日期：
目标岗位：
题目 ID / 页面：
练习前评分（0–4）：

## 我的原回答
不看资料时实际说了什么？

## 缺失的前提
版本、数据范围、权限、并发条件、输入约束是什么？

## 最小反例
给出能推翻原回答的一组输入、执行顺序或失败位置。

## 修正后的回答
先说结论和边界，再讲机制，最后说明验证。

## 证据
代码位置 / 测试命令 / 官方来源 / 实验记录。
哪些是实际运行结果，哪些只是设计预期？

## 下一轮追问
改变一个约束后，方案还成立吗？

练习后评分（0–4）：
下一次复访日期：
```

## 三种有效复盘

算法：不要只换一个答案，记录原代码在哪个输入违反了哪个不变量。系统设计：不要只补组件名，记录故障发生在提交前还是提交后。AI/Agent：不要只调 Prompt，记录问题发生在证据、决策、工具、状态还是验收阶段。

## 证据强度

正确的解释、可运行的小例子、目标环境的集成测试和真实业务数据不是同一层证据。某一层通过不能自动证明下一层；例如 SQLite 教学实验通过，不代表 MySQL 的所有锁行为也验证过。
