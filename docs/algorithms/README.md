## 每题的训练顺序

先识别输入约束和目标，再说不变量或状态定义，独立写 Java，最后给复杂度、边界用例和一个变式。看懂标准答案不等于能在陌生约束下迁移。

[ACM 输入、多组数据与对拍](./acm-testing.md) 专门处理溢出、EOF、输入重置和构造题非唯一答案。扩展测试包含固定种子的小规模暴力对拍，但随机测试不能替代正确性证明。
