# Skill：按需加载的工作方法

> 复习优先级：P0 · 整理与来源核验：2026-09-05

## 面试题：Skill、Tool、Agent 分别负责什么？

**60 秒回答：** Tool 提供可执行能力；Skill 描述何时使用能力、如何完成一类任务及如何验收；Agent 运行时依据用户目标选择并执行动作。Skill 可以包含脚本和参考文档，但写一份 Markdown 不会自动获得 API 权限或后台运行能力。

## 按需加载设计

启动时只索引名称与描述。命中任务后加载主体操作说明，需要细节时再读取参考文件，避免全部内容常驻上下文。Agent Skills 的通用结构以 `SKILL.md` 为核心，辅助材料可放在 `scripts/`、`references/` 和 `assets/` 中。

## 面试题：数据库查询 Skill 应写什么？

| 部分 | 内容示例 |
| --- | --- |
| 触发条件 | 用户要求根据业务代码查询数据并解释结果 |
| 前置条件 | 仓库可读、数据源已授权、工具可用 |
| 流程 | 定位代码 → 确认逻辑表与路由 → 查 Schema → 生成只读 SQL → 校验 → 执行 → 解释 |
| 失败分支 | Schema 不明时停止猜测；跨分片需要明确范围；超时不盲目扩大查询 |
| 验收 | 输出 SQL、数据源、时间范围、结果限制、证据与结论 |

这里的流程是教学设计，不代表已接通任何公司的内部平台。

## 常见追问

- **怎样避免多个 Skill 同时命中？** 描述写清适用范围和排除条件，用固定任务样本检验路由，必要时明确优先级。
- **Skill 可以替代后端鉴权吗？** 不能，指令必须由运行时约束和后端权限兜底。
- **为什么拆 references？** 降低无关 Token，便于局部维护；引用需要稳定路径与明确读取条件。
- **如何评估 Skill？** 与无 Skill 的同模型基线比较完成率、错误调用、Token 与人工修正次数。
