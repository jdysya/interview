# 资料来源与收录规则

本 Wiki 使用原创整理与题解，外部资料保留来源链接，不整篇搬运。**整理日期：2026-09-05**；“近期核验”页另列会影响回答的版本变化。

## 收录标准

- 优先官方文档、规范、原始论文、作者工程文章与题目原站。
- 说明适用版本、前提、反例和结论边界，不把某一实现细节写成通用保证。
- 新题必须有回答或解法，场景题明确设计假设，禁止编造公司真题来源。
- 外链原站可能调整或需要登录；站内保留自主编写的核心说明，便于持续复习。
- 页面修改后更新实际变更记录；Git 时间表示源码编辑时间，不自动等同技术事实核验时间。
