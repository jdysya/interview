# 学习路线

先确定目标岗位，以同一组基础能力连接不同方向。每轮学习采用“回忆回答 → 查缺补漏 → 写代码/画流程 → 做追问”的顺序。

## 四周安排

| 周次 | 重点 | 每周产出 |
| --- | --- | --- |
| 第 1 周 | Java 集合、并发、MySQL、Redis；哈希/链表/二分 | 10 个基础问题口述，3 道题独立实现 |
| 第 2 周 | LLM、RAG、混合检索、结构化输出；滑窗/树 | 一份 RAG 数据流和失败定位清单 |
| 第 3 周 | Agent 架构、MCP、Skill、上下文、幂等；图/DP | 一份带状态和验收条件的 Agent 方案 |
| 第 4 周 | 场景设计、消息可靠性、项目复盘；堆/LRU | 两轮完整模拟面试与错题回访 |

## 按岗位调整

- **AI 应用：** 优先 RAG、评测、延迟成本与后端数据基础。能够解释如何从 Demo 到可观测服务。
- **Agent：** 优先工具契约、执行状态、恢复与幂等、上下文预算和任务验收。
- **Java 后端：** 优先并发、事务、索引、缓存一致性、消息与系统设计，AI 专题作为应用加分项。

## 每日 60–90 分钟示例

20 分钟口述两个基础问题，30 分钟写一题并分析边界，20 分钟讨论一个场景的故障分支，最后记录一个尚未解释清楚的问题。时间不足时缩小题量，保留独立回忆环节。

## 自我评分

0：不会；1：能背定义；2：能解释机制与边界；3：能完成实现/推导并应对反例；4：有可复现的实验与权衡证据。分数只记录在自己的笔记中，本站不假装已经保存个人学习进度。
