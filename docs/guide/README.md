# 🧭 学习路线

先确定目标岗位，用“闭卷回答 → 查缺补漏 → 代码/推导 → 反例 → 复盘”完成一次学习。原有概览页用于快速复习，新增机制页和项目页用于深入追问。

## 四轮安排

| 轮次 | 重点 | 应交付的证据 |
| --- | --- | --- |
| 第一轮：基础 | Java、并发、MySQL、Redis，基础算法 | 口述机制、完成三道独立实现 |
| 第二轮：AI 应用 | 模型基础、RAG、检索、结构化输出、评测 | RAG 数据流与一个控制变量方案 |
| 第三轮：Agent | Runtime、MCP、Skill、上下文与恢复 | 工具契约、故障窗口、恢复实验 |
| 第四轮：项目 | 库存、审批、数据库 Agent 与模拟面试 | 状态图、关键代码和复盘记录 |

可以按一周一轮安排，也可以按薄弱项调整，不要求所有方向等量学习。

## 岗位优先级

| 岗位 | 先完成 | 再深入 | 训练入口 |
| --- | --- | --- | --- |
| Java 后端 | 并发、事务、索引、缓存、算法 | 消息、排障、业务状态机 | [后端路线](../practice/java-backend.md) |
| AI 应用 | RAG、结构化输出、评测、后端基础 | 推理资源、模型适配与服务实现 | [AI 路线](../practice/ai-application.md) |
| Agent | 工具契约、状态、幂等、任务验收 | 上下文、调度、长任务恢复 | [Agent 路线](../practice/agent-engineering.md) |

## 每日练习示例

20 分钟口述两个问题，30 分钟独立写题或做实验，20 分钟推导一个故障分支，最后记录尚未解释清楚的问题。时间不足时减少题量，保留独立回忆，不把“阅读过”当作“会回答”。
