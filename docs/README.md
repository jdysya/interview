# 面试知识库

**从会背答案，到能解释机制、推导故障、写出实现。**

面向 AI 应用、Agent 与 Java 后端开发，保留基础速查，也提供深入专题、可视化图示、算法代码和项目实验。

> 本轮扩充：30 道 Java 算法 · 36 道机制自测题 · 3 条项目深挖主线 · 9 种图示。题目、文章、实验分别计数，不虚构面试频率或上线成绩。
