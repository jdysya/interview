面向 **Java 后端、AI 应用开发与 Agent 开发**，整理可以独立学习的面试问题、机制解释、解题方法与系统设计。

## 资料怎样使用？

[资料来源](./guide/sources.md)区分两类证据：公开题库帮助检查“该覆盖什么问题”；官方文档与源码帮助判断“答案是否准确”。本站提供原创解释和反例，不整篇复制资料，也不要求读者自己把外链拼成答案。

不同来源出现概括冲突时，要明确前提并给出推导。例如缓存失效的常用写路径，不能被简化成无条件强一致；协议版本变化也不能靠刷新文章日期处理。
